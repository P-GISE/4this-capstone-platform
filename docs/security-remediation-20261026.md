# 2026-10-26 보안 수정

## 확인됨: 코드 변경

- 내 정보 수정은 세션의 사용자 ID로만 실행한다. 요청의 ID·역할·역할별 프로필은 바인딩하지 않는다. 관리자 전용 수정 기능은 별도로 유지한다.
- 해당 수정 경로와 DTO 진단 문자열에서 이름·이메일·전화번호 원문 로그를 제거했다. 프로젝트 전체 로그의 개인정보 제거를 의미하지 않는다.
- 보고서는 임의 파일명과 10MiB 한도로 저장하며 확장자·기본 파일 구조·경로를 검사한다. 정적 uploads 경로로 보고서를 읽는 것은 차단하고 기존 인증·권한 확인 다운로드를 사용한다. 새 다운로드에는 attachment·nosniff를 적용한다. 기존 파일과 DB 경로는 옮기지 않는다. 백신이나 완전한 문서 파서 검증은 아니다.
- 비밀번호 찾기는 기존 비밀번호를 즉시 바꾸지 않는다. 등록 메일로 전달한 32바이트 난수의 단회 토큰을 확인한 뒤에만 기존 해시와 비교하는 조건부 UPDATE를 실행한다. 계정 존재 여부·메일 오류는 같은 안내를 반환한다.
- 토큰은 SHA-256 해시로 메모리에 저장한다. 유효기간 15분, 최대 500개이며 재발급은 이전 토큰을 폐기한다. 요청은 15분당 계정 3회·주소 10회·전체 100회, 제한 상태 최대 5,000개다. 원문 토큰은 URL fragment로 받아 즉시 주소에서 지우며 서버 GET URL에 보내지 않는다.

## 운영 영향과 롤백

DB 스키마 변경과 데이터 이전이 없다. 비밀번호는 유효 토큰을 제출한 본인만 변경한다. 앱 재시작 시 아직 사용하지 않은 재설정 링크는 무효가 되며 다시 요청해야 한다. 다중 인스턴스 전환 전 공유 토큰 저장소가 필요하다. 프록시 원격 주소가 loopback인 경우에만 Cloudflare IP 헤더를 신뢰하며, 실제 배포의 IP 전달 방식은 별도 검증 대상이다.

검토 후 기존 이미지로 앱만 되돌릴 수 있지만 이전 이미지의 보안 결함도 다시 생긴다. 새 업로드 경로는 기존 reports 하위이며 DB 구조는 동일하다. pom.xml의 테스트용 UPLOAD_DIR 변경은 배포 감시기의 보호 대상이므로 검토한 기준 버전 승격을 거쳐야 한다. 감시기의 보호 규칙을 완화하지 않는다.

## 검증과 남은 범위

합성 데이터로 실제 H2·MyBatis·MockMvc 소유권과 비밀번호 조건부 갱신, 동시 토큰 소비, 만료·재사용·재시작·메일 실패, 실제 파일 저장과 Spring 정적 리소스 처리기를 검증했다. 실제 운영 메일 발송·운영 DB 수정·배포는 수행하지 않았다. MariaDB 통합 테스트는 별도 CI 서비스에서 확인해야 한다.

Spring 5/Javax 계열 의존성의 지원 종료와 보고된 취약점은 이 수정으로 해결됐다고 판정하지 않는다. 무검증 Jakarta 대규모 전환은 하지 않았다. 과거 SMTP 자격 증명 폐기, 전체 로그·템플릿·업로드 유형의 추가 검토도 별도 항목이다.
